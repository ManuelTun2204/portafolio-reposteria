# Portafolio de Repostería

Proyecto Dashboard Streamlit para portafolio profesional de repostería.

## Estructura
- `dashboard/app.py` - Aplicación principal Streamlit
- `dashboard/requirements.txt` - Dependencias Python
- `dashboard/.env.example` - Variables de entorno

## Descripción
Panel de análisis de portafolio de repostería profesional con secciones de:
- Recetas
- Posters
- Portafolio de imágenes fotográficas de productos

## Tecnologías
- Streamlit
- Pandas
- Plotly

## Despliegue
Ejecutar: `streamlit run dashboard/app.py --port 8501`
